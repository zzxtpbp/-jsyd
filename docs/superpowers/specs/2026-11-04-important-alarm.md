# 重要事项保障闹钟
用户已确认：重要事项单独开启；正常音量持续响铃，步数达标才能正常结束。走路期间不降音量、不贪睡、不因点关闭而结束。沿用此前提出的长按加确认应急退出，明确记录为手动退出。

本轮范围：独立纯状态模块、行为测试、网页模拟验收页及单文件构建脚本；不覆盖原页面、计算模块或调度。默认20步，可在启用前自定义1到200整数步（本版范围）。任务开始后冻结目标。

状态：armed → ringing → completed，或 ringing → manual_exit。仅计本次会话响铃后、单调序号的单步事件；旧会话、重复、未来或乱序事件不计入。无传感器/权限则拒绝启用，不生成看似有效的保障闹钟。

纯模块只消费可信原生适配层的步事件，不自行认证步行。网页按钮全部为模拟，只验证状态和前台声音；不假装提供真实计步或后台闹铃。

应急退出：连续长按8秒后再确认；释放未满8秒、取消、失焦或重开任务都清理旧授权。应急退出不等于步数达标。关机/系统停止/媒体输出仍受系统控制。
